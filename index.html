These are browser JavaScript measurements, not Python Suite 3.0 scores. Browser engine, power mode, background tasks, heat and browser APIs affect results. Typed-array operations are not physical DRAM bandwidth tests; IndexedDB is not a raw SSD benchmark; Web Worker timings include startup and messaging overhead.
